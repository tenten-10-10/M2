# SaaSGauge Pro Pack

Thank you! This pack turns the free SaaSGauge calculators into operational
templates you can put in front of your team, board and investors.

## What's inside
| File | What it is | Use it in |
|---|---|---|
| `saas-metrics-model.csv` | Monthly MRR-movement + unit-economics model with example data | Google Sheets / Excel |
| `MODEL-FORMULAS.md` | Exact spreadsheet formulas to make the model live | Reference |
| `benchmark-database.csv` | Benchmark ranges by metric, stage and segment | Sheets / filtering |
| `board-report-template.md` | One/two-page board & investor metrics update | Notion / Docs |
| `notion-metrics-dashboard.md` | Importable metrics dashboard structure | Notion |
| `fundraising-one-pager-template.md` | Investor metrics one-pager | Notion / Docs |
| `cheat-sheet.md` | All formulas + benchmarks on one page | Anywhere |

## Quick start
1. **Model:** Import `saas-metrics-model.csv` into Google Sheets
   (`File → Import → Upload`). Replace the example numbers with yours, then paste
   the live formulas from `MODEL-FORMULAS.md` into the computed rows.
2. **Dashboard:** In Notion, `Import → Markdown & CSV`, choose
   `notion-metrics-dashboard.md`.
3. **Reporting:** Copy `board-report-template.md` into your doc tool before each
   board meeting; fill the brackets.
4. **Benchmarks:** Keep `benchmark-database.csv` open to sanity-check each metric
   against your stage and segment.

## Notes
- All figures are inputs you control; benchmarks are directional and vary by
  stage, segment and market conditions.
- Educational tooling only — **not** financial, investment, accounting, tax or
  legal advice. Validate decisions with a qualified professional.
